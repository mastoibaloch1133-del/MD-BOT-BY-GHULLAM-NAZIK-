# 🤖 NAZIK-MD WhatsApp Bot

**Powered by nazuXhacker**

## 📌 Features

| Command | Description |
|---------|-------------|
| `.vcf` | Group members → VCF file (sent to DM) |
| `.numbers` | Group members numbers list (sent to DM) |
| `.once` | Send image/video as view-once to DM |
| `.help` | Show all commands |

## 🎁 Bonus
- **Auto ViewOnce** — Koi bhi view-once media aaye → automatically DM mein bhej dega

## 🚀 Deploy Options

- Railway
- Render
- Replit
- Koyeb

## 📱 Setup

1. Fork this repo
2. Deploy on Railway/Render
3. Add environment variable: `OWNER_NUMBER`
4. Pair code terminal mein aayega
5. WhatsApp → Linked Devices → Enter code
6. Bot ready ✅

## 🔧 Environment Variables

| Key | Value |
|-----|-------|
| `OWNER_NUMBER` | Your WhatsApp number (923001234567) |
